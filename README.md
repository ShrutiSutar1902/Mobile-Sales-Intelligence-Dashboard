# 📊 Mobile Sales Intelligence Dashboard

## 🔹 Project Overview

The **Mobile Sales Intelligence Dashboard** is an interactive Power BI project designed to analyze and visualize mobile sales data. It provides insights into sales performance, customer behavior, and trends using advanced data visualization and DAX calculations.

---

## 🔹 Features

📈 **Key Performance Indicators (KPIs)**

  * Total Sales
  * Average Sales
  * Total Quantity
  * Total Transactions

📅 **Time Intelligence**

  * Month-To-Date (MTD) Analysis
  * Year-over-Year (Same Period Last Year) Comparison

🌍 **Geographical Analysis**

  * Sales distribution across cities using map visualization

📊 **Detailed Insights**

  * Sales by Mobile Model and Brand
  * Monthly and Daily Sales Trends
  * Sales by Day of Week

💳 **Payment Analysis**

  * Transactions by Payment Method (Cash, Credit Card, Debit Card)

⭐ **Customer Insights**

  * Customer Ratings (Good, Average, Poor)

🎯 **Interactive Filters**

  * Mobile Model
  * Payment Method
  * Year
  * Month

---

## 🔹 Dashboard Pages

### 1. Overview Dashboard

* Displays overall sales performance
* Year and quarter-wise comparison
* KPI summary

### 2. MTD Dashboard

* Tracks cumulative sales over time
* Daily performance within a selected month

### 3. Detailed Insights Dashboard

* City-wise sales map
* Monthly and brand-level analysis
* Customer and payment insights

---

## 🔹 Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Excel / CSV Dataset

## 🔹 Key Insights

* Identified top-performing cities contributing to revenue
* Observed seasonal and monthly sales trends

1. Download the `.pbix` file
2. Open in Power BI Desktop
